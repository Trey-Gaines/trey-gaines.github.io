Trey Gaines Alerts

Automated website availability and service-status monitoring for invited users.

About the Application

Trey Gaines Alerts is a hobbyist-operated monitoring application that sends automated, non-marketing notifications when a configured website or service becomes unavailable, recovers, or reports a status change.

Enrollment is limited to invited users. Each user receives alerts only for monitored resources that the user selected or administers.

SMS Alerts

Invited users must explicitly subscribe before receiving SMS alerts. Message frequency varies according to monitoring events. Message and data rates may apply. Reply STOP to unsubscribe or HELP for assistance.
