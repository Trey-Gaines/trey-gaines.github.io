# Twilio A2P 10DLC GitHub Pages Site

This repo is a tiny static site for hosting public Privacy Policy and SMS Terms pages.

## URLs after publishing

If this repository is named:

    YOUR_USERNAME.github.io

then the URLs will be:

    https://YOUR_USERNAME.github.io/privacy/
    https://YOUR_USERNAME.github.io/terms/

If you use a normal project repository name, the URLs will include the repo name:

    https://YOUR_USERNAME.github.io/REPO_NAME/privacy/
    https://YOUR_USERNAME.github.io/REPO_NAME/terms/

## Before publishing

Optional but recommended:
- Replace "Personal Alert Service" in index.html with your registered Twilio brand/display name.
- If you want a support email, add it to the Terms page.
- Keep the Privacy and Terms pages public and accessible without login.

## GitHub Pages

Push these files to the `main` branch, then enable GitHub Pages from the repository settings.
